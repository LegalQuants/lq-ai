# v0.8.0 release notes

## Operator action: bundled object-store migration

This release replaces the unavailable MinIO image with digest-pinned RustFS
1.0.0 and introduces the journaled deployment-migration framework from ADRs
0036–0037. The application remains S3-generic.

Existing bundled-store installations must snapshot and migrate before RustFS
starts. macOS users must install the new app; the old app contains the obsolete
MinIO compose definition and cannot perform the migration.

Follow the dedicated
[MinIO to RustFS migration runbook](../runbooks/minio-to-rustfs.md) for:

- prerequisites, `pg_dump`, free-space checks, and exact Compose commands;
- macOS launcher behavior and the old-launcher failure mode;
- Helm and external/multi-drive paths;
- verification, rollback, and stable CLI exit codes; and
- the vendor-neutral `OBJECT_STORE_*` variables plus the `MINIO_*`
  compatibility window.

Do not run `docker compose down -v`. Legacy `MINIO_*` variables remain accepted
through at least v0.10.0; new installations should use
`OBJECT_STORE_SECRET_KEY` and the other `OBJECT_STORE_*` names. `RUSTFS_*`
appears only inside the container manifest where the RustFS process requires it.

## Experimental orchestration demonstration

The sample-only approval and parallel-work demonstration is off by default. To
enable it, set `LQ_AI_ORCHESTRATION_DEMO_ENABLED=true` and restart both the API and
arq worker. It uses synthetic findings and makes no live provider or source calls.
The shared worker retains its normal network access; demo children are governed
application runs, not network-isolated processes.

Drain or halt active demonstration runs before turning the flag off. Disabling
stops new approvals and worker execution, but does not itself halt or expire a
retained run. An active root can prevent its owner from starting another run while
recovery is off. On re-enablement, recovery may resume work before the approved
one-hour deadline; after it, the run expires or needs reconciliation. Owners can
still inspect and halt runs with the flag off.
