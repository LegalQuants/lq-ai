## Image cut and verification

After all pre-tag gates pass, a maintainer tags the approved commit in a **clean
LegalQuants-only clone**. This checkout imports OpenWebUI tags: its existing local
`v0.9.0` belongs to unrelated upstream history. Do not push that tag, force-update
an official tag, or use this checkout's `origin` (the houfu fork) for the release.

The following are cut-time commands for the maintainer, after recording the
approved SHA. Use a new destination directory and confirm the official tag is
still unused. In this dedicated clone, `origin` is explicitly LegalQuants:

```bash
set -euo pipefail
git clone --no-tags --single-branch --branch main \
  https://github.com/LegalQuants/lq-ai.git /tmp/lq-ai-v0.9.0-cut
cd /tmp/lq-ai-v0.9.0-cut
git remote get-url origin
# This check fails if either official tag exists. Set the reviewed, verified SHA:
test -z "$(git ls-remote --tags origin refs/tags/v0.9.0 refs/tags/desktop-v0.9.0)"
RELEASE_COMMIT='REPLACE_WITH_APPROVED_FULL_SHA'
git show -s --format='%H %s' "$RELEASE_COMMIT"
git merge-base --is-ancestor "$RELEASE_COMMIT" origin/main
git tag -a v0.9.0 "$RELEASE_COMMIT" -m "Release v0.9.0"
git push origin refs/tags/v0.9.0
```

## Recovery preparation

Retain v0.8.0 image digests, deployment configuration and a database backup.
The schema change has a downgrade that restores the old `now()` default; it does
not rewrite timestamps already recorded under 0069. Reverting application code
does not undo those rows. Rehearse any full database restore only on disposable
data, and plan for writes made after the backup.

For a hand-run stack, a fallback must repin **all four images** to verified v0.8.0
digests and recreate the API/workers consistently. It restores the #668 bug and
the old timeout. For the desktop, the v0.9.0 launcher reasserts its baked image tag
on launch; merely editing its generated `.env` is not a durable rollback. Use the
previous verified launcher with a compatible snapshot and verify the effective
pin before starting. Never reuse a released tag for different source or delete
volumes as a recovery step.
