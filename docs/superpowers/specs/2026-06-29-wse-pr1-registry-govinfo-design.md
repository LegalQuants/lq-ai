# WS-E PR1 — Content-source registry + GovInfo + DE-344 cost model (Design)

**Status:** Draft for maintainer review (2026-06-29). **Security-gated** (`gateway/**` egress adapter, `api/app/autonomous/**` chokepoint, `api/app/citation/**` ledger surface, migration).
**ADR:** [0021](../../adr/0021-content-source-registry-and-free-source-expansion.md) (accepted #241; D3 mechanism **refined to mirror the caselaw path** per the 2026-06-29 maintainer note in the ADR). Reuse anchors: [0014](../../adr/0014-gateway-egress-boundary-for-tool-providers.md) (gateway = only egress), [0015](../../adr/0015-governed-tool-calling-model.md) (closed-set, args validated), [0016](../../adr/0016-transparency-and-governance-invariants.md) (P3/P6), [0018](../../adr/0018-citation-ledger-and-fiduciary-grade-output.md) (ledger+gate), [0020](../../adr/0020-governed-agentic-legal-matter-sessions.md) (the agentic loop + `validate_action_args` boundary + WS-D PR2's `ledger_bridge`).

## Goal

The autonomous matter session (WS-D) can plan over a **registry of authoritative sources**, fetch authority from **GovInfo** (US federal statutes/regs) through the governed gateway egress, and have fetched quotes **character-fidelity-verified and fiduciary-ledger-backed** exactly like CourtListener caselaw — with a **real DE-344 cost model** so R4 throttles external tools. Reuse, never fork: one egress (gateway), one verifier (`verify()`), one ledger, one gate.

## Non-goals (deferred)

- **WS-E PR2:** SEC EDGAR + EUR-Lex adapters (same registry/intent/verify path, flagged); richer planner source-awareness (jurisdiction-matching in the planner prompt).
- **Chat-path `retrieve_authority`:** PR1 wires the intent into the autonomous loop. Chat-tool-loop authority retrieval is a follow-up (the chat loop has its own dispatch).
- MCP-server ingress (WS-F, Phase 3). `treatment_id`/WS-G linkage for authority (caselaw-only).

## Load-bearing invariants

1. **One egress (ADR 0014):** GovInfo is a new gateway tool-provider `type`; the backend reaches it ONLY via `gateway call_tool`. Secrets/auth/SSRF-allowlist/rate-limit stay gateway-side. No backend-direct HTTP to GovInfo.
2. **Closed-set, validated (ADR 0015):** one new `ToolIntent.retrieve_authority`; `source`/`op`/`args` are model-generated, **handler-validated against the live registry** (the WS-D `validate_action_args` boundary). An unknown/disabled source or unsupported op is a **non-fatal failed observation**, never an exception that escapes the governed path (the WS-D PR1-C1 lesson).
3. **Reuse the verifier + ledger + gate (ADR 0016 P6 / 0018; D3-refined):** fetched authority quotes are verified by the shared `verify()` core against an **in-memory target** (mirroring `caselaw.opinion_target`), persisted in ONE new `message_authority_citations` table, routed into the existing `citation_ledger_entry` + `compute_and_record_gate`. No ephemeral-`File`/`Document`/storage machinery; no parallel verifier.
4. **Honest degradation (ADR 0021 D5 / PRD §1):** a not-configured/disabled source is surfaced unavailable-with-reason (never silently dropped), never selectable; unverifiable quotes are dropped, never fabricated; coverage strings never imply comprehensive coverage.
5. **R4 real for external tools (DE-344):** `estimate_tool_cost` returns the configured per-provider rate; free sources ($0) stay un-throttled; realized cost recorded on `tool_call_log.cost_usd`.
6. **P3 (ADR 0016):** the registry/`/sources` response and planner-visible source metadata carry names/jurisdiction/coverage/ids only — never auth/cost secrets or raw payloads; the authority-citation rows store offsets/labels/refs, never full fetched text in audit/trace.

## Components

### C1 — Gateway GovInfo tool-provider adapter (`gateway/`)
New `gateway/app/providers/tool/govinfo.py` `GovInfoToolAdapter(ToolProviderAdapter)` mirroring CourtListener: `from_config` (type-check `"govinfo"`, resolve key), `_request` (auth header **`X-Api-Key: {key}`**, SSRF `validate_egress_target` against allowlist, status mapping), `invoke_tool` if/elif over ops, `_result(skip_anonymization=True)` (public statutory text must reach the verifier verbatim, ADR 0014 D5), `validate_base_url`, `health_check`. Ops (PR1): **`search_authority`** (`{collection, query, page_size?}` → result list with package/granule ids + titles) and **`get_authority`** (`{package_id|granule_id}` → `{text, title, citation, url, external_ref}`). PR1 collections: **USCODE + CFR** (statutes + regs — the highest-value caselaw complement). Register: add `"govinfo"` to `ToolProviderType` Literal (`config.py:150`) + a branch in `build_tool_adapter` (`main.py`) + export in `providers/tool/__init__.py`. Read `cost_per_call`/`cost_per_unit` via `getattr(provider, ..., None)` (model_extra). Tests: adapter unit (respx + stubbed DNS), Router integration (egress-log row), HTTP-route integration, auth/tier/rate-limit/unknown-op error mapping.

### C2 — Backend content-source registry + `GET /research/sources` (`api/`)
New `api/app/research/registry.py`: a declarative `SOURCE_REGISTRY: dict[str, SourceSpec]` keyed by provider **type** (`courtlistener`, `govinfo`), each `SourceSpec(type, jurisdiction, coverage, content_kinds, ops, adapter)`. A `resolve_available_sources(gateway) -> list[AvailableSource]` joins `list_tool_providers()` (operator-enabled, by type) with the registry (adapter-shipped) → the **intersection**; a not-registered or not-configured type is excluded; the result carries `{name, type, jurisdiction, coverage, content_kinds, enabled, egress_tier}` (NO secrets/cost). `GET /api/v1/research/sources` (owner-auth) returns it (PRD §3.6). Used by the `retrieve_authority` handler (validation) and the planner (source-awareness, minimal in PR1).

### C3 — `ToolIntent.retrieve_authority` + governance wiring (`api/app/autonomous/`)
Add `ToolIntent.retrieve_authority` (`enums.py`), grant in `PHASE_GRANTS[analysis]`, add to `PLANNER_ALLOWLIST` (so the WS-D loop can pick it) and `_EXTERNAL_TOOL_INTENTS` (so it flows through `_governed_external_dispatch` → tier + cost + `tool_call_log`). `_resolve_external_call`: for `retrieve_authority`, resolve `provider` from the registry by `params["source"]` (the gateway provider name for that source type) and `tool = params["op"]`. `_dispatch`/handler `_handle_retrieve_authority(params, db)`: validate source∈available + op∈source.ops (else raise → caught as failed observation), `call_tool(provider, op, args)`, run the C4 adapter `from_response`, write a `MessageToolSource` provenance row, return `ToolResult(data={fetched authority: text+refs+label})`. Extend `validate_action_args` (`planner.py`) with a `retrieve_authority` branch (source/op present + types; required args per op) — bad → `ValueError` → non-fatal failed observation. Extend `collect_evidence`/`EvidenceItem` with `kind="authority"` (ref = `external_ref`, content = fetched text) so the synthesis can quote-cite it (WS-D evidence registry).

### C4 — Backend source adapter (response → citable authority) (`api/app/research/`)
A backend `SourceAdapter` Protocol + `GovInfoAdapter`: `from_response(op, payload) -> FetchedAuthority` where `FetchedAuthority = {citable_text: str, label: str, subtitle: str|None, url: str|None, external_ref: str, content_kind: str}`. Keeps the parse of GovInfo's response shapes in one backend place (the gateway adapter is transport-only; the backend adapter is semantics). Registry `SourceSpec.adapter` points at it.

### C5 — DE-344 cost model
Extend the provider-config cache (alongside `resolve_provider_tier`, `governance.py`) to also cache `cost_per_call`/`cost_per_unit` from `/admin/v1/config` `tool_providers`. `estimate_tool_cost` (`cost.py`): for `retrieve_authority`/`retrieve_caselaw`/`call_mcp_tool`, return the configured per-call rate (default `Decimal("0")`). GovInfo free → $0 (R4 a no-op for it, correct). Realized cost on `tool_call_log.cost_usd` via the handler's `ToolResult.cost_usd` (= the gateway-reported cost if present, else the estimate). This makes R4 real by construction for any future metered source.

### C6 — Authority citation verify + ledger (mech-B, mirror caselaw)
- **Migration 0064:** `message_authority_citations` (id, message_id FK, `source_type`, `external_ref`, `source_offset_start/end`, `source_text`, `verified`, `verification_method` [req when verified], `verification_confidence`, `partial`; CHECK `offset_end > offset_start`, `(verified=false) OR (verification_method IS NOT NULL)`) + a 4th nullable FK `message_authority_citation_id` on `citation_ledger_entry` (extend the exactly-one-non-null CHECK to 4 slots) + a small `authority_text_cache(source_type, external_ref, text, fetched_at)` TTL table (cross-turn reuse; 30-day default TTL). Add the new models to `_AUDIT_MODELS`/P3 tripwire (refs/offsets only).
- **Verify path:** `ledger_bridge.build_authority_citations(db, *, message_id, citations: list[tuple[quote, source_type, external_ref]], gateway, judge_model)`: resolve text from `authority_text_cache` (or skip if absent), build an in-memory `_authority_target` (`uuid5(ns, external_ref)`, normalized_content=text) like `opinion_target`, `locate_passage(quote, text)` → offsets → candidate → `verify()` → verified `message_authority_citations` row only. Honest-degradation + empty-quote guard (WS-D PR2 lessons).
- **Session ledger integration:** `build_session_ledger` (WS-D PR2) splits finding citations into kb/caselaw/**authority** by the evidence-registry `kind` and calls `build_authority_citations`; `assemble_ledger_entries` already routes any `MessageToolSource`/citation rows by `message_id` — extend its citation-table reads to include `message_authority_citations` (source_kind = the authority content_kind). `resolve_ledger_entries` (the `/ledger` read) resolves the new slot.

## Error handling
- Bad/disabled source/op or bad args → `ValueError` in the handler/`validate_action_args` → the WS-D loop's `except Exception` → non-fatal failed observation (no DBAPIError, no poison).
- Gateway/GovInfo transport errors → the existing `_governed_external_dispatch` outcome handling (failed observation); the session continues honestly.
- The C6 verify + ledger runs inside WS-D PR2's **SAVEPOINT-isolated** `build_session_ledger` (a flush failure can't poison the terminal commit). Unverifiable quotes dropped.
