# Superseded orchestration workflow preview

This is a historical record of the first ADR 0035 workflow preview. It let an owner supply topics, approve a deterministic plan, watch parallel governed child sessions, and inspect sample findings and receipts. Its local sample provider used no model or live source. The recording demonstrated the run-tree mechanics only.

The sample-only page, creation API, operator switch, and bundled sample skills have been removed. The [bounded model-backed chat demonstration](issue-563-chat-demonstration.md) supersedes it and is the only supported experimental entry point. Its [UAT runbook](../runbooks/adr35-chat-uat.md) describes current setup and limits.
