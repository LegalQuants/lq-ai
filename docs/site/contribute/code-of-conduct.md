LQ.AI's community spaces — issues, pull requests, discussions, and the project's chat channels — run under the Contributor Covenant, version 2.1, adapted below only to name the project's enforcement contact. It applies to both contribution tracks equally: a disagreement over a skill's severity calibration is expected to stay as substantive and as civil as a disagreement over a code review, and the same escalation ladder applies either way.

This matters more than it might for a purely technical project. Skill review can produce real substantive disagreement between a practicing-attorney reviewer and a contributor — over a severity calibration, a piece of recommended language, whether a pattern the skill surfaces is actually unusual — and that disagreement is part of the value the review process is supposed to produce, not a symptom of something going wrong. The expectation stated in the text below is that disagreement stays focused on the work and on what best serves the in-house counsel using the skill, never on the contributor's identity, credentials, or background.

Reports of a violation go to the address named in the text below, not to a public issue or pull-request thread. They are reviewed confidentially by the people responsible for enforcement, and the enforcement ladder that follows scales from a private correction through to a permanent ban depending on severity and pattern.

The project adopted the Contributor Covenant as published rather than writing its own variant; the only project-specific element in the text below is the enforcement address, `conduct@legalquants.com`. Where this page might have paraphrased a clause instead, it includes the source document directly so the wording a contributor can rely on is never a summary once removed from the text that actually governs.
