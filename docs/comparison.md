# LQ.AI vs. the proprietary "fiduciary-grade" category — an evidence-linked comparison

A category of proprietary legal-tech products has begun describing its AI output as "fiduciary-grade" — verified, trustworthy, defensible. LQ.AI takes that ambition at face value: it is the right bar for AI-assisted legal work. Where this comparison differs is **the axis it measures on**. The proprietary category's announced direction is, per its own public statements, not yet shipped, and even once it ships, it will ship as a closed product whose internals a user cannot inspect. LQ.AI ships the same ambition — derive-don't-assert citation verification, a per-turn ledger of every source actually read, a pass/fail gate over every citation, governed agentic matter sessions, a derived (not editorial) treatment signal — **transparently, open-source, self-hosted, now.** Every row below resolves to one or more clickable artifacts — a design record, the source file that implements it, and/or an interactive playground you can run yourself.

This document is not a feature race. It is an argument that **verifiability is itself the capability that matters** for work a lawyer signs their name to.

## The three fundamental truths

**1. Demonstrable vs. asserted.** Every LQ.AI ✓ in the table below resolves to one or more clickable artifacts — an architecture decision record, the source file that implements it, and/or an interactive playground that lets you drive the logic yourself. A proprietary product's equivalent ✓ is a marketing claim or a support-page assertion; you cannot open the file that computes it, because there is no file you're allowed to see. The difference isn't that one side tries harder — it's that only one side lets you check.

**2. Show-the-work vs. trust-us.** An opaque editorial "this citation is good law" or "this output is verified" verdict is **architecturally** un-inspectable in a closed system — there is no mechanism by which a user could ever see the reasoning that produced it, only the label it was assigned. LQ.AI's citation and treatment layers derive their verdicts from passages the system actually read and expose the derivation itself, not just the label — transparency as a founding principle ([PRD §1.3](PRD.md#13-transparency-as-a-founding-principle)), applied as a competitive property rather than a compliance afterthought.

**3. Named accountability vs. committee-anonymized.** Legal work product built into a proprietary tool does not disclose a named individual accountable for the specific work product — responsibility diffuses across an anonymous engineering and editorial process, at least as far as the user can see. Every LQ.AI skill that touches legal substance carries a **named practicing-attorney attestation** as a condition of merge ([skills/CONTRIBUTING.md](../skills/CONTRIBUTING.md)) — a real person's name is on the work, the same way it would be if a junior associate handed it to you.

## How to read this table

The comparison axis is **verifiability, not capability**. The "Proprietary category" column never claims the category *lacks* a capability — that would be an unprovable strawman about products this project doesn't have access to audit, and it would undermine the very honesty this comparison is arguing for. Instead, that column states one fact, consistently: whatever the category claims, **it is closed-source, so the claim cannot be independently verified or forked by the user who has to rely on it.** The asymmetry is architectural, not competitive spin — and it's the whole argument. Where LQ.AI's own capability is partial or roadmapped, the caveat is stated inline, not buried in a footnote.

## Where LQ.AI is partial or roadmapped

Consistent with the honesty posture above, here is every place LQ.AI's own capability is partial today (mirrors [HONEST-STATE.md §5.6](HONEST-STATE.md#56-fiduciary-grade-agentic-legal-work-gateway-brokered-shipped-after-legal-research--mcp)):

- **Chat/autonomous fiduciary-gate verdict-tier parity is incomplete** — the attributed-authority FAIL tier for chat ([DE-370](PRD.md#9-deferred-enhancements-and-identified-future-work)) is shipped; an autonomous-path authority SUPPORTED tier ([DE-371](PRD.md#9-deferred-enhancements-and-identified-future-work)) is still open.
- **EUR-Lex is get-by-CELEX only** — no full-text search ([DE-374](PRD.md#9-deferred-enhancements-and-identified-future-work)); treaty/corrigendum CELEX formats aren't yet supported ([DE-375](PRD.md#9-deferred-enhancements-and-identified-future-work)).
- **No dedicated matter-intake UI yet** — governed matter sessions run through the existing autonomous session UI rather than a purpose-built "describe your matter" flow.
- **Anonymization recall is empirically unmeasured on a legal-document corpus** — the Presidio-based engine runs in production but has not yet been benchmarked against legal-specific PII patterns ([`docs/security/anonymization.md`](security/anonymization.md)).
- **Word add-in and intake-bridge surfaces are scaffolding, not full feature parity** — see [HONEST-STATE.md §6](HONEST-STATE.md#6-capabilities-not-yet-started-in-source) for the full accounting of what is deep-link-only vs. built out.
