Matters, org profile & privilege tiers: how context shapes a request

A matter's context — its org voice, attached files / skills / knowledge bases, and privilege posture — shapes every request it makes, and the privilege posture sets a tier floor the gateway enforces. All three capabilities shipped in M1.

1 · Configure the matter M1

Skills and documents attach at the request layer; knowledge bases attach per matter (matter_knowledge_bases, migration 0021).

2 · Organization profile M1

A per-org singleton (organization_profile, migration 0010). When configured, its voice, drafting standards, and house style inject into every skill request as a system-prompt layer.
