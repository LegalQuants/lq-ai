ADR 0018 D3 — the fiduciary-grade gate

In short: fiduciary-grade only when every citation is ledger-backed. (Paraphrase — not a verbatim quote of the ADR.)

In full: a drafted answer / memo / clause is fiduciary-grade iff every assertion's citation resolves to a ledger entry whose verification_status is in the PASS set, with no entry in the FAIL set left un-surfaced. SUPPORTED entries are permitted, but only labeled distinctly as “supported, not verbatim” — never presented as a verbatim quote.
